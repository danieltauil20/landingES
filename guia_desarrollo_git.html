🚀 Guía Definitiva: Entorno de Desarrollo, Servidor Local y Sincronización con GitHub

Manual paso a paso para abrir el proyecto desde cero, desarrollar con Tailwind v4 y mantener tu repositorio sincronizado sin errores de Windows.

React / Vite Tailwind CSS v4 Git & GitHub Windows PowerShell
Puntos clave a tener en cuenta antes de empezar:
  • Estructura del proyecto: La carpeta principal actúa como contenedor raíz de Git, mientras que el código de la aplicación de React/Vite reside en su respectiva subcarpeta interna.
  • Bloqueos en Windows (EPERM): Los archivos binarios internos de dependencias (como Vite o Tailwind) pueden bloquearse si el servidor local de desarrollo sigue ejecutándose en segundo plano. Apagarlo con Ctrl + C previene errores de permisos.
  • Sincronización limpia: Seguir un orden estricto al ejecutar comandos de Git garantiza que la nube y tu entorno local se mantengan alineados.

1 Cómo abrir y encender el proyecto desde cero

Cada vez que enciendas tu ordenador y quieras retomar el desarrollo de tu aplicación, sigue estos pasos:

  1. Abre Visual Studio Code.
  2. Ve al menú superior y selecciona File > Add Folder to Workspace... (Agregar carpeta al área de trabajo) y elige la carpeta principal del proyecto (LANDING EDIANNY SALAZAR).
  3. Abre la terminal integrada de VS Code (presionando Ctrl + `) y desplázate al directorio de trabajo ejecutando los siguientes comandos:
# 1. Ubicarse en la carpeta raíz del proyecto
cd "C:\Users\Jose Daniel\Desktop\LANDING EDIANNY SALAZAR"

# 2. Entrar a la subcarpeta interna donde reside el código de React/Vite
cd dra-edianny-salazar

# 3. Arrancar el servidor local de desarrollo
npm run dev
Resultado esperado: La terminal te proporcionará una URL local (generalmente http://localhost:5173). Mantén presionada la tecla Ctrl y haz clic sobre ella para abrirla en tu navegador. Deja esta ventana de terminal abierta mientras programes.

2 Cómo modificar código y guardar cambios

Mientras el servidor local esté corriendo, puedes editar cualquier componente, estilo o archivo de tu aplicación en Visual Studio Code. Al guardar con Ctrl + S, los cambios se reflejarán automáticamente en tu navegador gracias a HMR (Hot Module Replacement).

3 Sincronizar tus cambios con GitHub

Una vez que hayas terminado tus modificaciones y estés satisfecho con el resultado, sigue este procedimiento para empaquetar y respaldar tu código en la nube:

Paso A: Subir al directorio raíz de Git

Asegúrate de estar posicionado en la carpeta principal del repositorio (fuera de la subcarpeta interna) para que Git reconozca todos los cambios globales:

cd ..

Paso B: Añadir y confirmar los cambios localmente

Prepara los archivos modificados y asígnales un mensaje descriptivo de lo que realizaste:

git add .
git commit -m "Fix: descripción clara de los cambios realizados"

Paso C: Enviar a la nube (GitHub)

Sube tu trabajo al repositorio remoto para mantenerlo respaldado:

git push origin main
¿Qué pasa si hay un conflicto de versiones? Si GitHub contiene actualizaciones previas o diverge de tu historial local, Git te indicará que ejecutes git pull origin main --rebase antes de subir. Si experimentas bloqueos de archivos en Windows por dependencias temporales, recuerda apagar el servidor con Ctrl + C antes de operar.
